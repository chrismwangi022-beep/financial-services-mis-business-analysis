# Evidence Guidelines

Store only evidence that you are authorized to retain and share.

- Remove customer names, ID numbers, phone numbers, account details, and other sensitive information.
- Do not include passwords, access tokens, or confidential production data.
- Use screenshots only when sharing them is authorized.
- Give evidence files clear names and reference them from the relevant documentation.
- Distinguish direct observations from assumptions and unverified behavior.

No evidence should be treated as proof of a system behavior that it does not actually demonstrate.
